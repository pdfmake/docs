# Fuentes personalizadas (cliente)

Version: pdfmake 0.3.x
Language: es
Source: https://pdfmake.github.io/docs/0.3/es/fonts/custom-fonts-client-side/

pdfmake usa Roboto de forma predeterminada. Esta guía explica cómo utilizar tus propias fuentes con pdfmake en el código del cliente.

## Hay dos formas de hacerlo:
* [usar el sistema de archivos virtual](/docs/0.3/es/fonts/custom-fonts-client-side/vfs/)
* [usar un archivo de fuente mediante una URL con protocolo https:// o http://](/docs/0.3/es/fonts/custom-fonts-client-side/url/)
