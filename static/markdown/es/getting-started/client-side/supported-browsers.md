# Navegadores compatibles

Version: pdfmake 0.3.x
Language: es
Source: https://pdfmake.github.io/docs/0.3/es/getting-started/client-side/supported-browsers/

* Edge
* Firefox
* Chrome
* Chrome (Android)
* Opera
* Safari (iOS)
* Safari (iOS) iPhone


> **Note:** Los métodos **`open()`** e **`print()`** solo son compatibles con:

* Firefox
* Chrome
* Opera



> **Note:** Los complementos instalados en los navegadores pueden afectar al funcionamiento de pdfmake (especialmente a `open()` y `print()`). Si pdfmake no funciona, prueba a desactivar los complementos.
