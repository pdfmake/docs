# Start here

Version: pdfmake 0.3.x
Language: en
Source: https://pdfmake.github.io/docs/0.3/learn/

## Start with one working document

You do not need to learn the whole document reference first. Follow these three steps:



- [1. Make your first PDF](/docs/0.3/learn/first-pdf/): Understand the definition, load fonts and run one complete example.


- [2. Learn the document model](/docs/0.3/learn/document-model/): Know when to use a paragraph, inline text, a stack, columns or a table.


- [3. Read errors and fix the right thing](/docs/0.3/guides/errors/): Separate JavaScript syntax, document structure, resources and output.



## Which runtime do I need?

| Choose | When | Output |
| --- | --- | --- |
| [Node.js](/docs/0.3/getting-started/server-side/) | Your API or background job creates the file | `write()` for files; `getBuffer()` for HTTP responses |
| [Browser](/docs/0.3/getting-started/client-side/) | The user creates the document on their device | `download()`, `open()`, `print()` or `getBlob()` |

The document definition is shared. Font loading and output helpers depend on the runtime.
These pages target **0.3.x**; older examples using `new PdfPrinter(...)` and callback
output belong to [0.1/0.2](/docs/0.3/migration-from-0.1/).

## Learn by seeing the result

Examples in this learning path show the exact JavaScript definition beside a real
generated PDF. Open them in the playground to edit them. Their complete source is
also included in the [Markdown corpus](/docs/0.3/llms-full.txt), including the code
otherwise generated by the interactive example components.
