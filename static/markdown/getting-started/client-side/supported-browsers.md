# Supported browsers

Version: pdfmake 0.3.x
Language: en
Source: https://pdfmake.github.io/docs/0.3/getting-started/client-side/supported-browsers/

* Edge
* Firefox
* Chrome
* Chrome (Android)
* Opera
* Safari (iOS)
* Safari (iOS) iPhone


> **Note:** Methods **`open()`** and **`print()`** are supported only in:

* Firefox
* Chrome
* Opera



> **Note:** Add-ons used in browsers can affect the functionality of pdfmake (especially for `open()` and `print()`). If pdfmake is not working try disable add-ons in browser.
