# Navigateurs pris en charge

Version: pdfmake 0.3.x
Language: fr
Source: https://pdfmake.github.io/docs/0.3/fr/getting-started/client-side/supported-browsers/

* Edge
* Firefox
* Chrome
* Chrome (Android)
* Opera
* Safari (iOS)
* Safari (iOS) iPhone


> **Note:** Les méthodes **`open()`** et **`print()`** ne sont prises en charge que dans :

* Firefox
* Chrome
* Opera



> **Note:** Les extensions de navigateur peuvent affecter le fonctionnement de pdfmake (en particulier `open()` et `print()`). Si pdfmake ne fonctionne pas, essayez de désactiver les extensions du navigateur.
