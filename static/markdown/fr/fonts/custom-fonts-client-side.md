# Polices personnalisées côté client

Version: pdfmake 0.3.x
Language: fr
Source: https://pdfmake.github.io/docs/0.3/fr/fonts/custom-fonts-client-side/

pdfmake utilise Roboto par défaut. Ce guide explique comment utiliser vos propres polices avec pdfmake dans du code exécuté côté client.

## Deux méthodes sont possibles

- [Utiliser le système de fichiers virtuel](/docs/0.3/fr/fonts/custom-fonts-client-side/vfs/)
- [Utiliser un fichier de police via une URL (protocole https:// ou http://)](/docs/0.3/fr/fonts/custom-fonts-client-side/url/)
