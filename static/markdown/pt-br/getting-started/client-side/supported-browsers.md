# Navegadores compatíveis

Version: pdfmake 0.3.x
Language: pt-br
Source: https://pdfmake.github.io/docs/0.3/pt-br/getting-started/client-side/supported-browsers/

* Edge
* Firefox
* Chrome
* Chrome (Android)
* Opera
* Safari (iOS)
* Safari (iOS) iPhone


> **Note:** Os métodos **`open()`** e **`print()`** são compatíveis apenas com:

* Firefox
* Chrome
* Opera



> **Note:** As extensões instaladas no navegador podem afetar o funcionamento do pdfmake (especialmente `open()` e `print()`). Se o pdfmake não funcionar, tente desativar as extensões do navegador.
