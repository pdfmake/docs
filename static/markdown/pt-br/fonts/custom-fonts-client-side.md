# Fontes personalizadas no cliente

Version: pdfmake 0.3.x
Language: pt-br
Source: https://pdfmake.github.io/docs/0.3/pt-br/fonts/custom-fonts-client-side/

Por padrão, o pdfmake usa a fonte Roboto. Este guia explica como usar suas próprias fontes com o pdfmake no código do cliente.

## Há duas opções:

* [usar um sistema de arquivos virtual](/docs/0.3/pt-br/fonts/custom-fonts-client-side/vfs/)
* [usar um arquivo de fonte por URL (`https://` ou `http://`)](/docs/0.3/pt-br/fonts/custom-fonts-client-side/url/)
