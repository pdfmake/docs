# Eigene Schriften im Browser

Version: pdfmake 0.3.x
Language: de
Source: https://pdfmake.github.io/docs/0.3/de/fonts/custom-fonts-client-side/

pdfmake verwendet standardmäßig die Schrift Roboto. Diese Anleitung erklärt, wie du in Browser-Code eigene Schriften mit pdfmake verwendest.

## Es gibt zwei Möglichkeiten:
* [Verwende ein virtuelles Dateisystem](/docs/0.3/de/fonts/custom-fonts-client-side/vfs/).
* [Verwende eine Schriftdatei über eine URL (https://- oder http://-Protokoll)](/docs/0.3/de/fonts/custom-fonts-client-side/url/).
