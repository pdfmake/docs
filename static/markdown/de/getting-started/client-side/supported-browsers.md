# Unterstützte Browser

Version: pdfmake 0.3.x
Language: de
Source: https://pdfmake.github.io/docs/0.3/de/getting-started/client-side/supported-browsers/

* Edge
* Firefox
* Chrome
* Chrome (Android)
* Opera
* Safari (iOS)
* Safari (iOS) iPhone


> **Note:** Die Methoden **`open()`** und **`print()`** werden nur in folgenden Browsern unterstützt:

* Firefox
* Chrome
* Opera



> **Note:** Browser-Erweiterungen können die Funktion von pdfmake beeinflussen (insbesondere `open()` und `print()`). Wenn pdfmake nicht funktioniert, deaktiviere testweise die Erweiterungen.
